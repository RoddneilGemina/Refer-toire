Built for Choral Directors & Ensemble Singers

Pair your group with an 8-character access code and access complete rehearsal scores instantly.

🔑

Access Code Instant Sync

Choristers connect in seconds using an ensemble access code. The app automatically pairs with the database and downloads all current scores into local storage.

🎼

High-DPI Mozilla PDF.js Reader

Crystal-clear sheet music canvas rendering with device pixel scaling. Supports single-page turns, vertical continuous scrolling, and Bluetooth foot pedal navigation.

🎭

Concert Hall Stage Mode

Inverts sheet music to crisp white & gold notation on an ultra-dark background to eliminate face glare and preserve night vision in dimmed performance halls.

⚡

100% Offline Storage

All repertoire scores are saved directly on your device. Rehearsals in ancient stone cathedrals, basements, or Wi-Fi dead zones proceed without dropouts.

📚

Voicing & Liturgical Filter

Filter and group repertoire by SATB, SSAA, TTBB, Liturgical Season (Advent, Lent, Easter, Ordinary Time), composer surname, and rehearsal setlists.

📤

File-First PDF Uploads

Directors can add new scores via device file chooser with automated title parsing, broadcasting instant synchronization to all ensemble members.
